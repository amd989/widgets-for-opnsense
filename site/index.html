01

DHCP Leases

The devices on your network, newest first, so the one that just connected is on top. Cards show hostname, IP, vendor and how long ago it joined, color coded as new, active, reserved or stale. Works with ISC DHCP and Kea, detected automatically.

02

Traffic

Live download and upload speed, sampled every second from the interface byte counters. The WAN is found by name, and the large size charts every interface, so LAN, VLANs and VPN tunnels each get their own line.

Firewall

Which rules are matching the most traffic right now, as a live donut. Labels come from the rule descriptions you set in OPNsense, and raw pf rules are turned into readable names like "NAT · LAN → WAN".

privacy

It only talks to your firewall.

The app reads leases, interface counters and rule statistics from the address you enter, and makes no other connections. The API key stays in Windows Credential Manager, or your desktop keyring on Linux. Self-signed certificates work, since most home firewalls use one.

setup

Up and running in a few minutes.

  1. Create a read-only API user

    In OPNsense, make a group under System › Access › Groups, give it only the privileges the widgets need, add a user to it and create an API key. Don't use root.

    WidgetPrivilege
    DHCP Leases (Kea)Services: DHCP: Kea(v4)
    DHCP Leases (ISC)Status: DHCP Leases
    TrafficDiagnostics: Netstat
    FirewallFirewall: Rules, Diagnostics: Firewall statistics, Diagnostics: Netstat

    Privilege names move around between OPNsense versions. The README lists the exact API endpoints.

  2. Install

    Windows: from the Microsoft Store once it's approved, or build and deploy the MSIX from source with Visual Studio.

    Linux: build the service and run the installer. It sets up the Plasma widgets or the GNOME extension, whichever desktop you have.

    dotnet publish src/OPNsenseWidgets.Linux -c Release -r linux-x64 -o linux/dist
./linux/install.sh linux/dist/opnsense-widgetsd

  3. Connect

    Add a widget and open its settings. Enter the firewall address, then either type the key and secret or click Import Key to read the *_apikey.txt file OPNsense just downloaded. Test, Save, done. All widgets share the one connection.
