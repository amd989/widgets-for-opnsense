# Microsoft Store listing (en-us)

## Product name
Widgets for OPNsense

## Description
Keep an eye on your OPNsense firewall from the Windows 11 Widget Board (Win+W), without opening the web UI.

Widgets for OPNsense adds three widgets, each in small, medium and large sizes:

DHCP Leases: the devices on your network, newest first, with new and reserved devices marked and a 24-hour activity line. Works with both ISC DHCP and Kea.
Traffic: live download and upload speed for your WAN, with per-interface charts for LAN, VLANs and VPNs, and running totals.
Firewall: which rules are doing the work right now, as a live donut chart with evaluations per second.

Setup takes a minute: enter your firewall's address and an API key from OPNsense (System > Access > Users), or import the key file you downloaded. Self-signed certificates are supported, since most home firewalls use one.

The widgets only talk to your own firewall over its API. Nothing is sent anywhere else, there is no account, and your API key is stored in Windows Credential Manager.
